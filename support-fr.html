Assistance

Questions, signalement de bug ou suggestions : zhangwei798879@gmail.com. Indiquez le modèle de votre téléphone, la version du système et la version de l’app affichée dans les Réglages.

Ce qu’il vous faut

  • L’app Stowplay sur iPhone, iPad ou Android.
  • Le Stowplay Local Agent sur votre propre ordinateur ou NAS, avec accès aux dossiers que vous voulez gérer. L’app ne travaille qu’avec les fichiers que vous y autorisez.
  • Un chemin réseau entre le téléphone et l’Agent : le même réseau domestique, ou un outil d’accès à distance privé, comme un VPN, quand vous êtes à l’extérieur.

Stowplay gère vos propres fichiers et sauvegardes. Il ne télécharge, ne vend ni ne fournit de jeux, et ne contrôle pas les consoles.

Installer l’Agent

NAS ou tout hôte Docker : téléchargez compose.yaml et env.example, enregistrez ce dernier sous le nom .env, indiquez vos identifiants d’utilisateur et de groupe, l’adresse du NAS et vos dossiers, puis lancez docker compose up -d. Pour appairer : docker compose exec agent stowplay-pair, puis scannez le code. Mise à jour : docker compose pull && docker compose up -d.

Windows 10/11 (64 bits) : téléchargez StowplayAgent-0.1.0-win-x64.zip, décompressez-le et double-cliquez sur Install Stowplay Agent.cmd. Choisissez vos dossiers de jeux (lecture seule) et de sauvegardes, autorisez le pare-feu Windows, puis scannez le code QR affiché.

Mac (macOS 12 ou ultérieur, Apple silicon et Intel) : téléchargez StowplayAgent-0.1.0-macos.zip, décompressez-le et double-cliquez sur Install Stowplay Agent.command. La première fois, macOS peut le bloquer car il n’est pas encore notarié : ouvrez Réglages Système → Confidentialité et sécurité et cliquez sur « Ouvrir quand même ».

Tous les fichiers et sommes de contrôle : version Stowplay Agent 0.1.0. L’Agent est gratuit.

Appairer votre téléphone

  1. Lancez l’Agent. Il affiche un QR code d’appairage à usage unique, valable deux minutes.
  2. Dans l’app, ouvrez Réglages → Connexions → Connecter un nouvel Agent, puis scannez le code.
  3. Si le code a expiré, générez-en un nouveau sur l’Agent. Les codes expirés ou déjà utilisés sont toujours refusés.

L’appareil photo affiche un écran noir

iOS coupe l’appareil photo pendant que l’écran du téléphone est consulté ou recopié sur un Mac (par exemple dans une app de gestion d’appareils ou de recopie d’écran). Arrêtez la recopie, puis scannez à nouveau. Vous pouvez aussi utiliser « Ou collez le JSON d’appairage de l’Agent ».

Utilisation hors de chez vous

Stowplay n’expose pas votre Agent sur Internet. Pour vous connecter depuis l’extérieur de votre réseau domestique, utilisez une solution d’accès à distance privée que vous contrôlez (par exemple un VPN). N’ouvrez pas directement le port de l’Agent sur votre box ou votre routeur.

Notifications

  • Quand l’app est ouverte : Réglages → Notifications → Activer les notifications système. Vous pouvez choisir les catégories affichées.
  • Quand l’app est fermée (facultatif) : Réglages → Push quand l’app est fermée → Réglages du push. Cochez « Activer le push » et touchez Enregistrer. Installez ensuite l’app gratuite ntfy et abonnez-vous à l’adresse affichée. Par défaut, les messages indiquent seulement qu’il y a une nouvelle notification. Gardez le nom du sujet privé ; utilisez « Nouveau nom de sujet » pour le changer.

Sauvegardes et restaurations

  • Fermez le jeu avant de sauvegarder ou de restaurer, pour que ses fichiers ne changent pas.
  • Chaque restauration sauvegarde d’abord la partie actuelle et vérifie chaque fichier ensuite. Si une copie de sauvegarde est endommagée, la restauration est refusée et rien n’est écrasé.
  • Si une restauration demande votre attention, choisissez à nouveau une version et consultez l’aperçu. Les anciennes tâches de restauration ne peuvent pas être relancées à l’aveugle.

Dissocier et supprimer les données

Réglages → Connexions → Dissocier l’Agent actuel (l’Agent doit être en ligne). Cela révoque l’accès du téléphone et supprime la connexion locale. Vos fichiers et sauvegardes sur l’Agent ne sont pas supprimés. Voir la politique de confidentialité pour plus de détails.
