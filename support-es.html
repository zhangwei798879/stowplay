Soporte

Preguntas, reportes de errores o comentarios: zhangwei798879@gmail.com. Incluye el modelo de tu teléfono, la versión del sistema y la versión de la app que aparece en Ajustes.

Lo que necesitas

  • La app Stowplay en iPhone, iPad o Android.
  • El Stowplay Local Agent en tu propia computadora o NAS, con acceso a las carpetas que quieras administrar. La app solo trabaja con los archivos que autorices ahí.
  • Una ruta de red del teléfono al Agent: la misma red de tu casa o, cuando estés fuera, una herramienta privada de acceso remoto, como una VPN.

Stowplay administra tus propios archivos y partidas guardadas. No descarga, vende ni proporciona juegos, y no controla consolas.

Emparejar tu teléfono

  1. Inicia el Agent. Muestra un código QR de emparejamiento de un solo uso, válido por dos minutos.
  2. En la app, abre Ajustes → Conexiones → Conectar nuevo Agent y escanea el código.
  3. Si el código caducó, genera uno nuevo en el Agent. Los códigos caducados o ya usados siempre se rechazan.

La cámara se ve en negro

iOS apaga la cámara mientras la pantalla del teléfono se está viendo o duplicando en una Mac (por ejemplo, en una app de administración de dispositivos o de duplicación de pantalla). Detén la duplicación y vuelve a escanear. También puedes usar “O pega el JSON de emparejamiento del Agent”.

Uso fuera de casa

Stowplay no expone tu Agent a Internet. Para conectarte desde fuera de tu red doméstica, usa una solución privada de acceso remoto que tú controles (por ejemplo una VPN). No abras directamente el puerto del Agent en tu router.

Notificaciones

  • Con la app abierta: Ajustes → Notificaciones → Activar notificaciones del sistema. Puedes elegir qué categorías mostrar.
  • Con la app cerrada (opcional): Ajustes → Push con la app cerrada → Ajustes de push. Marca “Activar push” y toca Guardar. Después instala la app gratuita ntfy y suscríbete a la dirección que se muestra. De forma predeterminada, los mensajes solo avisan que hay una notificación nueva. Mantén privado el nombre del tema; usa “Nuevo nombre de tema” para cambiarlo.

Respaldos y restauraciones

  • Cierra el juego antes de respaldar o restaurar, para que sus archivos no cambien.
  • Cada restauración primero respalda la partida actual y después verifica cada archivo. Si una copia de respaldo está dañada, la restauración se rechaza y no se sobrescribe nada.
  • Si una restauración requiere atención, vuelve a elegir una versión y revisa la vista previa. Las tareas de restauración anteriores no se pueden reintentar a ciegas.

Desemparejar y eliminar datos

Ajustes → Conexiones → Desemparejar el Agent actual (el Agent debe estar en línea). Esto revoca el acceso del teléfono y elimina la conexión local. Tus archivos y partidas en el Agent no se eliminan. Consulta la política de privacidad para más detalles.
