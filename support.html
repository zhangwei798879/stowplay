What you need

  • The Stowplay app on iPhone, iPad or Android.
  • The Stowplay Local Agent running on your own computer or NAS, with access to the folders you want to manage. The app only works with files you authorize there.
  • A network path from the phone to the Agent: the same home network, or a private remote-access tool such as a VPN when you are away.

Stowplay manages your own files and saves. It does not download, sell or provide games, and it does not control game consoles.

Install the Agent

NAS or any Docker host: download compose.yaml and env.example, save the second file as .env .env.example to .env, enter your user/group IDs, the NAS address and your folders, then run docker compose up -d. To pair, run docker compose exec agent stowplay-pair and scan the code. Update later with docker compose pull && docker compose up -d.

Windows 10/11 (64-bit): download StowplayAgent-0.1.0-win-x64.zip, unzip it and double-click Install Stowplay Agent.cmd. Choose your game folders (read-only) and your save folders, allow the Windows Firewall prompt, then scan the QR code that opens.

Mac (macOS 12 or later, Apple silicon and Intel): download StowplayAgent-0.1.0-macos.zip, unzip it and double-click Install Stowplay Agent.command. The first time, macOS may block it because it is not notarized yet: open System Settings → Privacy & Security and click “Open Anyway”.

All files, checksums and notes: Stowplay Agent 0.1.0 release. The Agent is free.

Pairing your phone

  1. Start the Agent. It shows a one-time pairing QR code that is valid for two minutes.
  2. In the app, open Settings → Connections → Connect new Agent, and scan the code.
  3. If the code has expired, generate a new one on the Agent. Expired or used codes are always refused.

The camera shows a black screen

iOS turns off the camera while the phone's screen is being viewed or mirrored on a Mac (for example in a device-management or screen-mirroring app). Stop the mirroring, then scan again. You can also paste the pairing JSON from the Agent instead.

Using it away from home

Your Agent is not exposed to the internet by Stowplay. To connect from outside your home network, use a private remote-access solution that you control (for example a VPN). Do not open the Agent port directly on your router.

Notifications

  • While the app is open: Settings → Notifications → Turn on system notifications. You can choose which categories to show.
  • When the app is closed (optional): Settings → Push when the app is closed → Push settings. Turn on "Enable push" and tap Save. Then install the free ntfy app and subscribe to the address shown. By default messages only say that there is a new notification. Keep the topic name private; use "New topic name" to change it.

Saves and restores

  • Close the game before backing up or restoring, so its files are not changing.
  • Every restore first backs up the current save and checks every file afterwards. If a backup copy is damaged, the restore is refused and nothing is overwritten.
  • If a restore needs attention, choose a version again and review the preview. Old restore tasks cannot be retried blindly.

Unpairing and removing data

Settings → Connections → Unpair current Agent (the Agent must be online). This revokes the phone's access and removes the local connection. Your files and saves on the Agent are not deleted. See the Privacy Policy for details.
